Domain 5 · Metadata
Tagging Strategy & Taxonomy
Define mandatory and optional resource tags. A consistent tagging taxonomy is the foundation of cost attribution, security classification, and operational management.
🏷️ Enforcement: Mandatory tags enforced via AWS Config rule required-tags and SCP denying resource creation without mandatory tags. Non-compliant resources flagged in Security Hub.
